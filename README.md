# Rottenwood — Free Offline Installer

![Category](https://img.shields.io/badge/Movie_Tracker-blue?style=flat-square)

## About

Rottenwood is a macOS and iOS movie tracker that integrates Rotten Tomatoes scores, Metacritic ratings, and streaming availability data. Track movies you want to watch, log what you've seen, get notified when a movie arrives on your streaming subscriptions, and discover new films through curated lists. Rottenwood is a polished native Apple platform app for movie enthusiasts.

## Common Problems & Limitations

- **Apple Only** — macOS and iOS; no Android or Windows version
- **Streaming Data Accuracy** — Streaming availability data may lag real-world changes
- **Commercial License** — Paid application
- **Limited Social** — Sharing and social features less developed than Letterboxd
